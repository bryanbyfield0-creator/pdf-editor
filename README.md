# PDF Editor

A free, simple PDF editor that runs entirely in your browser. There is no sign-in and nothing to install. Open the link, pick a PDF, edit it, and download the result.

**Your files never leave your device.** The editor does not upload your document to a server.

**Live site:** https://bryanbyfield0-creator.github.io/pdf-editor/

## How to use

1. Open a PDF with the button, or drag and drop a file onto the page.
2. Pick a tool: **Text**, **Draw** (for handwriting or a signature), **Highlight**, **White-out**, or **Image** (for a signature photo).
3. Click or drag on the page. Use **Select** to move an item, and drag any of the corner or edge handles to resize it (this works with a mouse or touch). **Delete** removes the selected item.
4. Use the page strip to rotate, reorder, or remove pages. Set **Page size** to Letter, A4, or a custom percentage. **Add PDF** merges another file at the end.
5. If the PDF has form fields, you can fill them in on the page.
6. Optionally check **Smaller file** to compress photos and images, then tap **Download**. Use **Undo** if you need to go back a step.

Works on phones and computers.

## Privacy

All editing happens in your browser. The PDF is not sent anywhere.

## Limitations

- Password-protected PDFs cannot be opened.
- Added text uses the Helvetica font, so some special or non-English characters may be replaced.
- Very large PDFs can feel slow on a phone.
- Form filling works for common text fields, checkboxes, and dropdowns.
- Edits are baked into the downloaded file (they are not a separate “comment layer”).
- **Smaller file** shrinks photos and images you add, and tries to recompress bitmap images already in the PDF. Vector text stays sharp. Some image types (for example JPEG2000 or JBIG2 scans) may not shrink, and text-only PDFs often stay about the same size. A few unusual PDFs may not compress as much as a dedicated desktop tool.
- Changing the page size fits the original page onto Letter or A4 (or scales it by a percentage). Extra margins may appear if the shape does not match exactly.

This tool is free to use and share.
